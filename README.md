# বার্ষিক ক্রীড়া প্রতিযোগিতা (Sports Portal)

বার্ষিক ক্রীড়া প্রতিযোগিতার ইভেন্ট, অংশগ্রহণকারী ও ফলাফল পরিচালনার জন্য একটি আধুনিক ওয়েব পোর্টাল।

## 🚀 বৈশিষ্ট্যসমূহ (Features)
- 🏆 **ইভেন্ট ও ফলাফল ট্র্যাকিং**: বিভিন্ন ক্রীড়া ইভেন্টের সময়সূচি ও ফলাফল পরিচালনা।
- 👥 **অংশগ্রহণকারী ব্যবস্থাপনা**: অ্যাথলিট ও দলীয় অংশগ্রহণকারীদের তথ্য সংরক্ষণ।
- 🥇 **পদক ও স্কোরবোর্ড**: রিয়েল-টাইম স্কোরবোর্ড ও পদক তালিকা প্রদর্শন।
- 📱 **রেসপন্সিভ ডিজাইন**: মোবাইল ও ডেস্কটপ উভয় ডিভাইসেই ব্যবহারের উপযোগী।
- 🌐 **বাংলা ইন্টারফেস**: ব্যবহারকারীদের সুবিধার্থে সম্পূর্ণ বাংলা ইন্টারফেস।

## 📁 ফাইল বিবরণী
- `index.html`: মূল ওয়েব অ্যাপ্লিকেশন ইন্টারফেস।
- `styles.css`: স্টাইল ও লেআউট ডিজাইন।
- `app.js`: অ্যাপ্লিকেশনের লজিক ও ইন্টারঅ্যাক্টিভিটি।
- `sports-portal.html`: অফলাইন বা সহজে চালানোর জন্য সম্পূর্ণ বান্ডল্ড একক ফাইল সংস্করণ।
